# Handoff continuity

- This project uses `HANDOFF.md` at the repository root so work can move between Claude Code, Codex, and OpenCode.
- Read `HANDOFF.md` at the start of a session when it exists.
- Keep its `Status` section with `Now`, `Next`, and `Why` current after finishing a meaningful chunk of work or before running low on context or usage.
- Never hand-edit its `Activity Log`; it is auto-generated.
