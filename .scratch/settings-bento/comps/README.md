## Shared prompt contract

- Match the shipped Settings tile geometry and Voni's restrained neutral rendering.
- Preserve the frozen endpoint story for the tile.
- Keep key glyphs at least 16px inside the crop and leave fade space below for the tile copy.
- Keep structure graphite. Reserve Voni green for a traveling marker, pulse, presence dot, or state-change moment.
- Use only compositions that can be reproduced with semantic tokens, React, SVG, and CSS.
- Exclude page chrome, tile copy, badges, photos, filler text, glass effects, clipped glyphs, and watermarks.
