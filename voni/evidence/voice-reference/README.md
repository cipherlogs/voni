This is the reference A5 judges the delivered capture against: one line in the
English demo voice, rendered by the cascade's own synthesis path outside any
conversation. It is committed because a reference regenerated by the live run
it judges is a gate that cannot fail.

The body is the smallest served body that names the voice and the greeting:

```json
{
  "system_prompt": "You are Voni, a voice agent demo.",
  "greeting": "Hi, I'm Voni! Let's try something cool: I'll show you what I can do while we talk. Ready?",
  "voice": { "voice_id": "audrey" },
  "input": { "language_codes": ["en"] }

```

A re-render must produce a new sidecar and a deliberate commit: the loader
(`voni/src/lib/audio/voice-reference.ts`) refuses a hash or format that no
longer matches, and `A5` fails closed when the pair is absent. The reference is
the comparison baseline, never a threshold; the bars stay in the frozen budget
record (`timbreMeasured*`).
